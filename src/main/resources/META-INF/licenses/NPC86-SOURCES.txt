699 Russian dialogue translations and their semantic color anchors were authored
for this local project. Per-record URLs and pinned revisions are embedded in
data/witherskyru/npc-expansion86.json. Full pages, original blocks, conditions,
all occurrences and latest API verification are preserved in the source package.
21 authored recipe item names are separately attributed to the linked Alcina
dialogues in NPC_RECIPE_SOURCES_0.15.86.json in that package.

Public sources are not access to unpublished server scripts or proof that every
historical event branch is currently active. Existing translations were retained.
