689 Russian dialogue translations and explicit semantic color anchors were
independently authored for this local project. Per-record source URLs with pinned
revision IDs are embedded in data/witherskyru/npc-expansion85.json. Full original
pages, contexts, occurrences, current API revision verification and the exact
reviewed editorial-only revision delta are retained in the source package.

The dataset is a public publication snapshot, not access to unpublished server
scripts. Historical event dialogue is retained as historical source material,
not represented as a currently active event. Existing translations were retained.
