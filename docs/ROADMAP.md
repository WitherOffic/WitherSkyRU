# Дорожная карта

План не является обещанием сроков или полного покрытия.

## Основной перевод

- [ ] Контекстная проверка названий и описаний из свежих ресурсных выгрузок.
- [ ] Тексты новых погодных событий и обновлённых меню.
- [ ] Расширение реплик NPC по подтверждённым оригиналам, с сохранением имён, действий и чисел.
- [ ] Улучшение отображения длинных текстов и проверка разных размеров интерфейса.
- [ ] Проверка совместимости с Bazaar Utils и другими модами без изменения оригинальных игровых данных.
- [ ] Отдельный безопасный подход к 3D-надписям/голограммам.

## Возможный аддон SkyHanni

Пока только оценка возможности, не реализован.

- [ ] Отдельный необязательный компонент и отдельный счётчик покрытия.
- [ ] Перевод отображаемых названий/описаний настроек MoulConfig по ключам настроек.
- [ ] Перевод HUD, уведомлений и собственных окон после распознавания данных.
- [ ] Сохранение исходных команд, идентификаторов, конфигов и регулярных выражений.
- [ ] Ограничение совместимыми версиями и выключатель интеграции.
- [ ] Офлайн-проверка меню, поиска и сохранения настроек до ручной игровой проверки.

## Публикация и качество

- [ ] Воспроизводимая сборка с Gradle Wrapper и проверенной конфигурацией GitHub Actions.
- [ ] Ручные игровые проверки тестового выпуска; документировать результаты и не скрывать ошибки.
- [ ] Дальнейший разбор происхождения данных перед публикацией на площадках модов.
- [ ] Исправления сообщества и согласованный словарь терминов.

ИИ используется как инструмент подготовки, а не доказательство качества. Автоматические проверки не заменяют игровой контекст.
