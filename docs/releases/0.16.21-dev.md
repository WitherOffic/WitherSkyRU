# SkyblockRPG_RU 0.16.21-dev — Minecraft 26.2 / Fabric

**Experimental prerelease.** AI-assisted Russian localization of Hypixel SkyBlock. Translation is incomplete and may contain mistakes. Full-game translation coverage is unknown.

## Included in this development build

- Seven accepted UI translation batches, 1000 new source strings each, plus reviewed NPC dialogue additions.
- Optional NPC Dialogue Overlay compatibility for the verified SkyCubed 1.10.0 / SkyBlock API 4.2.41 versions.
- Public display name and JAR renamed to **SkyblockRPG_RU**. Fabric mod ID and configuration directory remain **witherskyru**.
- Offline dictionaries, numeric templates, user overrides and local unknown-string logging. Player chat, signed messages and input remain protected.
- No embedded Collector, network telemetry, registration, upload or consent prompts. The separate Collector is optional and is not called by this mod.
- Bundled MIT code license, OFL font license and third-party/source attribution; wiki-derived translations retain their stated CC BY-NC-SA terms. See THIRD_PARTY_NOTICES.md.

## Requirements and installation

Minecraft **26.2**, Java **25+**, Fabric Loader **0.19.5+**, and Fabric API with Resource Loader v1. Put only the production JAR in the instance mods folder and remove older versions of this same mod. Existing config/witherskyru settings remain compatible.

## Validation and limits

The published JAR is the previously verified 0.16.21-dev artifact, not a replacement under an existing version number. Source fingerprints match the verified checkpoint. Release preparation repeats the automated checks and public archive/bytecode inspection; current results are recorded in DEV_STATUS.md.

Previous isolated Minecraft 26.2 / Java 25 client validation passed. It was not a live Hypixel gameplay test. The current release preparation does not claim new in-game, FPS, frame-time or heap measurements. WSRU-0002 and WSRU-0003 still await visual confirmation in game. Recent Collector findings are analysis only and have not been fixed in this release.
