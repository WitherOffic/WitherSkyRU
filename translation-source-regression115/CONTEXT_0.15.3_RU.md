# 0.15.3-dev: поиск предметов по русским названиям в RRV

Пользователь показал пустую правую панель при запросе «Кирка» в Search RRV:
английское имя находило предмет с русской подсказкой, русский запрос — нет.
Проверен байткод локального reliable-recipe-viewer-8.10.9+26.1.2-fabric.jar.
Метод ItemFilters.defaultFilter(String) читает ItemStack.getDisplayName()
и проверяет lowercase startsWith/contains и наличие всех слов. Имена
не переводятся глобально (намеренная защита данных и других модов).

## Решение

RrvSearchMixin redirect заменяет только локальный результат getDisplayName
в defaultFilter на временный компонент с английским и русским именами.
Оригинальное имя остаётся в строке; запрос не переписывается. Английские
запросы возвращают тот же оригинальный Component без перевода. Русские
варианты имеют приоритет contains, а не startsWith английского имени;
список результатов может ранжироваться иначе, чем английский поиск.
Фильтры по ID, namespace, тегам, компонентам и иным служебным префиксам
не изменяются. Поиск по русскому lore, REI и ванильная книга рецептов
этим патчем не реализованы. Неизвестные названия не угадываются.

CompatibilityMixinPlugin допускает только rrv 8.10.9+26.1.2. @Pseudo и
строковая цель исключают обязательную зависимость на RRV. При отсутствии
или другой версии интеграция пропускается; сам мод продолжает работать.
Не заменять защиту широким >= без проверки соответствующего байткода.

RussianSearchAliases кэширует до 16384 имён, добавляет вариант е вместо ё.
SkyRuClient.searchName проверяет active(); отключённый мод/не Hypixel
не добавляет aliases. OfflineDictionary.translateForSearch использует
тихий режим без записи unknown.tsv и без заполнения общего display-кэша.
Иначе просмотр тысяч каталожных предметов загрязнил бы журнал наблюдений.

регистр, е/ё, английский путь, исходный Component/Style, неизвестные имена,
ограничение кэша, выключенный мод, версия интеграции и отсутствие логирования.
Прежние тесты прошли: 7 словаря, 73511 редакторских, 77 чата, 6517 HUD,
7924 читаемости подсказок, 2368 перековок. Проверено применение настоящего
redirect к установленному RRV через Fabric с копией Fabric API и отдельно
трансформация без RRV. Инициализации entrypoints/вызова Minecraft.main нет.
Тесты matcher используют алгоритм сопоставления из проверенного байткода;
это не живая проверка поискового окна и не замер FPS/скорости каталога.

Процент полноты перевода всего сервера неизвестен.
