# WitherSkyRU 0.15.11-dev: расширенная проверка названий экипировки

11 октября 2026 года. Minecraft 26.1.2 Fabric.

## Проверка локальной базы

Из сохранённого item-context.json (8940 предметов) выделены записи с явной
категорией оружия, брони или инструмента в строке редкости: 1139 записей,
1124 уникальных имени. Категории: SWORD, LONGSWORD, BOW, HELMET, CHESTPLATE,
LEGGINGS, BOOTS, AXE, HOE, PICKAXE, DRILL, FISHING ROD, WAND, FARMING TOOL.

Для каждого имени проверены наличие перевода и композиция с Fierce, без
звёзд и с тремя звёздами: 2248 вариантов композиции. На 0.15.10 было
84 замечания (включая повторные варианты одного имени), после исправлений
замечаний в этом наборе нет. Ожидаемые формы массового теста берутся из
таблиц; это проверка работоспособности, а не независимая ручная вычитка
1124 названий. Дополнительно независимые ожидания закреплены для 20
предметов разных типов в TestArmorTooltip.

| Проверяемая величина | Результат |
| --- | ---: |
| Уникальные имена экипировки в проверке | 1124 |
| Варианты композиции с Fierce | 2248 / 2248 |
| Замечания массового теста | 84 → 0 |
| Новые авторские уточнения рода | 116 |
| Всего авторских уточнений рода | 129 |
| Точные ключи словаря / шаблоны | 35617 / 1215 |

100% относится только к прохождению этих вариантов проверки. Число всех
строк текущего сервера неизвестно; процент полного перевода SkyBlock
не пересчитывался, прежний снимок покрытия не перегенерирован.

## Исправления

- Разбор декораций теперь сначала ищет самое длинное известное имя.
  Цифровые индексы, точки, запятые и скобки внутри названия не мешают
  переводу после добавления звёзд. Проверены буры TX-15 / SX-R226 и другие
  модели, инструменты Mk. I–III, Necron's Blade (Unrefined).
- Род модификатора согласуется с русским названием, а не только с
  серверной категорией: маски, короны, головы, катаны, косы, рубашки,
  туники, Астрея, Сцилла, Валькирия — женский; сердца, жало, копьё,
  пальто — средний; очки — множественное число. Кирконимбус и
  Бингонимбус — мужской. Это закрытые авторские записи, не угадывание.
- Добавлены три прежде отсутствовавших имени: Bingonimbus 2000,
  etalptsehC norI, woB. У двух предметов Разлома сохранена идея зеркального
  написания: «киндурган йынзелеЖ», «куЛ». Исправлено Mithril Coat →
  «Мифриловое пальто». Идентификаторы и серверные названия не меняются.
- Новый StyledItemTitle объединяет фрагменты только узнаваемого названия.
  Отдельно переводятся префикс и базовое имя с сохранением их эффективного
  Style, событий клика/наведения, жирности/курсива/шрифта. Звёзды сохраняют
  собственный стиль. Дробление имени на одноцветные буквенные компоненты
  теперь не оставляет его английским. Результаты разбора кэшируются (LRU
  4096); длинный текст и нерелевантные строки не обрабатываются как имя.
- Для безопасности произвольные разные стили внутри самого базового
  имени не объединяются: используется прежний перевод фрагментов.
  Суффиксные перековки/полные пользовательские переопределения с перестановкой
  слов требуют единого стиля заменяемого участка. Поэтому универсальная
  поддержка любого стороннего оформления не заявляется.

Примеры: «Свирепая Маска жнеца», «Свирепая Катана расщепления атомов»,
«Свирепое Кристальное сердце», «Свирепые Очки иссушителя»,
«Свирепый Мифриловый бур SX-R226 ✪✪✪».

## Проверки готового JAR

3679 проверок перекованных/зачарованных предметов; 3017 проверок подсказок
брони и расширенного набора экипировки. Для 20 независимых названий проверены
четыре варианта декораций, цветной префикс, побуквенные компоненты имени,
действия стиля, неизменность исходника, обычный и защищённый Shift-вывод.

Пройдены прежние тесты словаря, редакторских исправлений, чата, HUD,
читабельности, ввода, шрифтов и Inter. Пройдены изолированная трансформация
классов Minecraft, совместный русский/английский поиск настоящих классов
RRV 8.10.9 и SkyRecipes 0.5.13. Пользовательские редкости остаются на
английском, поля ввода не переводятся. Размер шрифта в этой партии не менялся.

Папка проверки: build/jar-verification-0.15.11-dev-cadd496b025247e6b91840d9a330e70e/.

Это офлайн-проверки, не запуск игры. Hypixel не посещался. ItemStack,
NBT, игровые пакеты, установленная сборка и старые JAR не изменены.
