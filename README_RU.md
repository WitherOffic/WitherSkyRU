## Архив 73: меньше копий строк при защите имён игроков

Обычные слова HUD сравниваются с именами игроков прямо внутри текущей строки,
без создания отдельной строки на каждое слово. Дополнительная таблица хранит
только имена текущего списка игроков и ограничена 1024 позициями. Сложные
коллизии и большие списки используют прежнюю проверку через Set.

Правила регистра, границ имени, форматирования и обновления состава игроков
сохраняются. Новых кадровых перехватов, кэша контекста, изменений F3 или данных
перевода нет. Это локальная оптимизация, не доказательство устранения всех
микрофризов или нулевого влияния на FPS. Сборка игры автоматически не меняется.
Результаты проверки и ограничения — translation-source/OPTIMIZATION_0.15.73_RU.md.

## Архив 72: готовый перевод повторяющегося текста

Повторяющиеся форматированные строки используют сохранённый план символов
вместо повторного перевода. Актуальные цвета, шрифты, команды и подсказки
подставляются при выводе, а не сохраняются в кэше. Изменившиеся счётчики
и таймеры обрабатываются по новому содержимому, поэтому значения не замирают.

Небольшая проверка изменений и отрисовка Minecraft остаются необходимыми.
Кэш ограничен 128 позициями и общим бюджетом 16 384 символов плана на поток;
длинные/сложные строки используют обычный путь. Предметы, ввод, F3 и защита
имён сохраняют прежние правила. Ресурсы переводов не менялись.

Проверки, замеры и ограничения — translation-source/PREPARED_0.15.72_RU.md.
Это не обещание нулевой нагрузки или устранённых микрофризов: новая версия
нуждается в игровом сравнении. Автоматической замены JAR в игре нет.

## Экранные интерфейсы

Стандартные тексты меню, кнопок и подсказок предметов проходят через уже
подключённые обработчики. Переводятся только известные фразы и шаблоны.
Проверка локального JAR SkyHanni показала путь TextRenderable → RenderableUtils
→ GuiRenderUtils.drawString → GuiGraphicsExtractor.text. Последний метод
для String, Component и FormattedCharSequence уже перехватывается нашим модом.
Поэтому обычные текстовые панели SkyHanni технически доступны переводу,
включая обсуждавшуюся статистику лесорубства. Это статический разбор кода,
не проверка её фактического отображения в игре.

Покрытие всех строк HUD, Tab, правой панели и других модов пока не подтверждено.
Фразы, разрезанные цветами, переводятся по отдельным стилевым частям; это может
давать неполный перевод. Разметка сторонних панелей может рассчитываться по
ширине английского текста, поэтому отсутствие наложений тоже не проверено.
Текстуры с надписями не распознаются; отдельного обработчика для голограмм
и имён над сущностями сейчас нет. Распознавание экрана и онлайн-перевод не нужны.

## Первый обработчик NPC-чата

NpcChatMixin подключается к ChatComponent.addMessageToDisplayQueue до
переноса сообщения на строки. Он подменяет только копию для отображения;
по разобранному коду оригинал сохраняется в истории и журнале. Это схема
реализации, не результат игрового теста. Новый Mixin пока не проверен загрузчиком.

Допускаются только SYSTEM_SERVER без подписи и с точным совпадением полной
реплики с нашей выборкой. Тип PLAYER исключён; похожий префикс сам по себе
не включает перевод. Имена NPC и [NPC] сохраняются. Обработчик не отправляет
ответы, команды или пакеты и не записывает неизвестный чат для сбора диалогов.

Поддерживаются буквальные компоненты, унаследованные стили и §-цвета:
однообразное оформление тела реплики и явно указанные смысловые якоря.
Неподдерживаемое дерево, неоднозначное оформление, неизвестная реплика или
ошибка возвращают исходное сообщение. Для известных смысловых областей
сохраняются исходные стили и действия. Произвольные цветные слова и события
не переносятся наугад. Перевод вариантов ответа и динамических NPC-шаблонов
ещё не реализован. Даже 21 совпадающая реплика может остаться оригинальной
при неподдерживаемом оформлении; все диалоги SkyBlock не заявляются.

Приоритет словарей: базовые фразы → ванильные названия → словарь терминов →
ручные фразы → описания → продолжение → зачарования → названия → питомцы → сгенерированный каталог →
пользовательские overrides.tsv. Генератор переводит только известные
семейства и целые шаблоны; неизвестные строки не угадываются.

## Настройки

После будущего запуска создаётся config/witherskyru/settings.properties:

```properties
enabled=true
onlyHypixel=true
recordUnknown=true
translateNpcChat=true
```

Перевод включается на hypixel.net и его поддоменах. Обычный пользовательский
чат не является приоритетом. После изменения настроек нужен перезапуск.
Неизвестные фразы общего словаря записываются в config/witherskyru/unknown.tsv.
Отдельный NPC-обработчик неизвестные диалоги не записывает. В существующем
settings.properties отсутствие translateNpcChat означает true, файл не
перезаписывается; false отключает именно новую NPC-поддержку.
Свои исправления можно добавить в overrides.tsv: UTF-8, исходная фраза,
табуляция, русский перевод. Пользовательские записи имеют высший приоритет.
