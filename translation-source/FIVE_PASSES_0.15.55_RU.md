# Пять проходов по мешкам — 0.15.55-dev

14 октября 2026. Скриншот6bd25cbc: смешанное описание Combat Sack,
неудачная вместимость, склеенная дата получения.

1. 24 обычных мешка: шесть видов ресурсов, начальный/малый/средний/большой.
2. Шесть мешков зачарованных ресурсов: описание целиком, без смешения языков.
3. 31 специализированный/событийный мешок: камни, руны, наживки, мутации,
   острова, подземелья и события. Цветные названия не объединяются с серой
   фразой; «The»/«Year of»/«Mutations» имеют отдельные границы стиля.
4. Четыре трофейных мешка рыбы/лягушек: bronze/silver качество,
   названия, требования, вместимость, привязка. Исправлен род названий для
   безопасного перевода фрагментированных букв; редкость остаётся английской.
5. Общие подписи: вместимость в единицах, суммирование мешков, ПКМ,
   SACK→МЕШОК, привязка, частичный «По2,240», разделитель Received.
   Точная частичная Combat-фраза со скриншота включена в тест.

65/65 текущих полных карточек с описанием:28683 проверки, Component/Sequence,
четыре раскладки цвета, пять свежих наборов действий и пять повторов.

защищены. Даты не переинтерпретируются: Received получает разделитель,
