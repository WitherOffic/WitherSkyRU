# Контекст 0.14.2 — игровые уведомления

Пользователь показал английский чат и одобрил добавление игровых уведомлений
с отдельным тестовым JAR. На момент работы установлен 0.14.0-dev, SHA
FC667A19A652BC6A9B287DF1EED8DE772E8389DA2ED13F0DE39EC6D703BE6F7B.
Установленный файл не менялся. Этот выпуск включает подгонку HUD 0.14.1.
Ни установка, ни запуск игры/автоматизация Hypixel не выполнялись.

Источники: скриншот codex-clipboard-0ce961ab-707e-471f-ad38-30198852509e.png
и совпавшие строки latest.log 01:56-01:58. Это сообщения сервера и модов,
не NPC-диалоги. Прежний обработчик whitelist NPC21 их не переводил.

ChatNotificationTranslator сопоставляет полное сообщение после необязательной
метки HH:mm:ss: редкая добыча, монеты с гоблина, объявление Powder Ghast,
его локация, бестиарий/заголовок, уведомление магазина SkyHanni, найденное
шоколадное яйцо Skyblocker, сводка мешков. Динамические значения не
размножаются в искусственные «новые строки». Источники/примеры/ограничения:
CHAT_NOTIFICATIONS_0.14.2.json. Каноническое имя из старого словаря:
«Порошковый гаст», не новая параллельная терминология.

В SkyRuClient.npcChat сохранена существующая точка очереди отображения,
добавлен fallback к уведомлениям: сначала прежние NPC (только SYSTEM_SERVER),
затем уведомления SYSTEM_SERVER/SYSTEM_CLIENT. PLAYER/подпись исключаются.
Причина разрешения SYSTEM_CLIENT: моды перепечатывают системные сообщения
в локальный чат. Это не разрешение на произвольный перевод реплик игроков:
строгие полные шаблоны исключают ранги/ники/обычный чат/неизвестные команды.
translateGameChat по умолчанию true, независимо от translateNpcChat; существующая
конфигурация не перезаписывается. Обе функции можно отдельно выключить.

Коллектор компонента учитывает унаследованные Style и legacy §-цвета,
сохраняет non-literal ObjectContents целыми (особенно головы/значки).
Редактируются только авторские смысловые диапазоны; для каждого нужно
однозначное форматирование. Неизвестный стиль/пересечение значка/большой
компонент/неузнанный полный шаблон -> исходный объект. Никаких сетевых
кодеков или изменений ItemStack, подписи/история/метаданные сообщения целы.
Порядок Chocolate Dinner Egg -> «шоколадное яйцо (ужин)» меняется с явным
переносом стиля Egg и Dinner к соответствующим русским словам.

Проверки: 61 чат/стили/legacy/значки/команды/координаты/защита PLAYER/
подписей/флагов/NPC, 6512 HUD-политики, 7 словаря; применение 5 миксинов
к4 реальным классам через Fabric без Minecraft.main и игрового цикла.
Не утверждать, что все живые сообщения переведены или формат каждого
сервера/мода уже проверен в игре. Неизвестный предмет внутри rare drop или
локация могут остаться английскими, используется только прежний словарь.

Исходный снимок/NPC-объединение: 32544/33147, 98,18%, остаток603, включая
частичные переводы — неизменно. Новые 8 семейств уведомлений сообщаются
отдельно: общий объём живого чата и процент покрытия неизвестны.
NPC21 не пополнены и не объявляются всеобщим переводом диалогов.
