# Полный доступный список coverage117-001

Сводная таблица и методика: [отчёт](../../docs/translation-runs/coverage117-001.md).

Откройте coverage.csv и отфильтруйте status:

| Значение | Смысл |
| --- | --- |
| registered_exact | Точный ключ есть; целевой текст и фактический вывод в отдельных колонках |
| changed_without_exact_review | Точного ключа нет, вывод меняется; шаблон/композиция, качество ещё проверять |
| unchanged_review | Ключа и срабатывания нет в найденных контекстах; требуется проверить видимость/имена/переменные |

Колонка offline_changed не означает законченный качественный перевод. Корпуса пересекаются, сумма групп не равна общему числу. Не называть весь unchanged_review «непереведённой игрой». source_url и JSONL origins сохраняют контекст/ревизию/позицию. SHA-256 исходника — стабильный ID после удаления только цветов и внешних пробелов. API split — только реальные newline, не придуманная ширина строки.

В exports.zip находятся полные JSONL, corpus/probes/runtime-probes, runtime-inventory и runtime-patterns. README/лицензии/машинные итоги сохранены рядом. Zip содержит контрольные хеши каждого файла. Источники и корпус закреплены на21.10.2026; не перезаписывать снимок при следующем этапе.
