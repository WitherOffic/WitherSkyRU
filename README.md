# WitherSkyRU

Локальный русский перевод **Hypixel SkyBlock** для **Minecraft 26.1.2 / Fabric**.

> **Это нейроперевод в разработке.** Тексты подготовлены с использованием ИИ и постепенно исправляются. Возможны ошибки смысла, неудачные формулировки, пропуски и проблемы совместимости. Не обещаем 100% перевода или безошибочную работу.

Во время игры мод использует готовый локальный словарь и шаблоны. Он не обращается к нейросетям, платным API или внешним сервисам перевода. Использование ИИ при подготовке проекта не означает использование ИИ во время игры.

## Что умеет мод

- Переводит известные названия предметов, описания, меню, характеристики, задания и локации через поддерживаемые пути отображения.
- Обрабатывает числовые шаблоны, сохраняя суммы, координаты, уровни и игровые значки.
- Переводит выбранные реплики NPC и распознанные игровые уведомления. Обычные сообщения игроков и подписанный чат не переводятся этим обработчиком.
- Сохраняет стили, действия по клику и наведения в поддерживаемых компонентах текста.
- Подгоняет длинные переводы в известных HUD-панелях и подсказках. Это не универсальный исправитель интерфейсов.
- Оставляет неизвестный текст оригинальным вместо выдуманного перевода.

Редкости `COMMON`, `UNCOMMON`, `RARE`, `EPIC`, `LEGENDARY` и аналогичные метки намеренно остаются английскими. Имена игроков, команды и собственные имена могут также сохраняться.

## Установка

1. Сделайте резервную копию сборки и настроек.
2. Откройте [Releases](https://github.com/WitherOffic/WitherSkyRU/releases) и скачайте JAR для Minecraft **26.1.2**.
3. Закройте Minecraft. Уберите старый JAR WitherSkyRU из папки `mods`, сохранив его отдельно для отката.
4. Положите новый JAR в `mods` нужного экземпляра. Не оставляйте две активные версии WitherSkyRU одновременно.
5. Запустите сборку самостоятельно. Если возникают вылеты, отключите мод и приложите очищенный от личных данных журнал к сообщению об ошибке.

Fabric API не указан как отдельная зависимость самого WitherSkyRU; остальные моды вашей сборки могут его требовать. Совместимость с другими версиями Minecraft не заявляется.

## Настройки и приватность

После первого запуска настройки находятся в `config/witherskyru/settings.properties`. После изменения нужен перезапуск Minecraft.

| Настройка | Назначение |
| --- | --- |
| `enabled` | Включить мод |
| `onlyHypixel` | Ограничить работу подключением к Hypixel; по умолчанию `true` |
| `translateNpcChat` | Перевод выбранных реплик NPC |
| `translateGameChat` | Перевод распознанных игровых уведомлений |
| `fitHudText` | Подгонка текста известных HUD-панелей |
| `compactHudLabels` | Короткие подписи HUD |
| `fitTooltipText` | Подгонка поддерживаемых подсказок |
| `recordUnknown` | Локально сохранять неизвестные тексты для дальнейшего разбора |

Существующие настройки не перезаписываются. Для точечных исправлений можно использовать `config/witherskyru/overrides.tsv`: `исходный текст<TAB>русский перевод`.

**Локальный журнал неизвестных текстов включён по умолчанию.** Он может содержать имена и другой текст, показанный игрой или сторонними модами. Чтобы отключить запись, установите `recordUnknown=false`. Мод сам не загружает этот журнал в интернет. Не публикуйте весь журнал, конфиги или чат без проверки и удаления личных данных.

## Ограничения и честные проверки

- Полной базы всех меню, NPC-веток, сезонных событий и динамических сообщений SkyBlock у нас нет.
- 3D-голограммы и надписи над сущностями не имеют универсального обработчика. Текст, встроенный в изображения, не переводится словарём.
- Неизвестные рендереры сторонних модов могут обходить обработчики перевода. В узких блоках текст может стать мелким.
- **Полная совместимость с Bazaar Utils не подтверждена.** Мод старается менять отображение, а не исходные игровые данные, но это не гарантия отсутствия конфликтов.
- Полноценного перевода интерфейса SkyHanni и отдельного аддона для него пока нет.
- Для 0.15.0-dev прошли 73 459 редакторских, 77 чатовых, 6 512 проверок политики HUD и семь проверок словаря. Проверена целостность JAR. Эти автоматические проверки не заменяют ручную вычитку и тестирование в игре.
- Текущий выпуск не проходил полноценную игровую проверку всей сборки или подтверждённую проверку совместимости на Hypixel.

Проект не связан с Hypixel, Mojang или Microsoft и не имеет их официального одобрения. Мы не заявляем, что использование мода гарантированно допустимо правилами сервера или защищает от санкций; пользователь должен проверить актуальные правила самостоятельно.

## Как помочь

Создайте [Issue](https://github.com/WitherOffic/WitherSkyRU/issues). Укажите версию мода, место/меню, английский оригинал, текущий перевод и смысл ошибки. Скриншот с соседними строками полезнее одной обрезанной фразы. Сначала закройте или замажьте личные данные.

Исправления через Pull Request приветствуются. При помощи ИИ укажите это и объясните, как проверяли игровой контекст. Числа, параметры, команды, значки и стили нельзя изменять ради красивого текста.

## Сборка из исходников

На Windows с установленными в Prism Launcher Minecraft 26.1.2 и Java 25:

```powershell
./build-local.ps1
```

Для другого расположения Prism передайте `-PrismRoot`. Результат появится в `build/libs`. Скрипт использует уже установленные зависимости; он не устанавливает мод в сборку и не запускает Minecraft.

Есть также Gradle-конфигурация, но Gradle Wrapper в этом первом публичном снимке отсутствует. Воспроизводимый кроссплатформенный процесс сборки запланирован; автоматическую сборку на GitHub Actions пока не заявляем.
