# SkyblockRPG_RU — правила разработки

## Начало работы и область чтения

- При начале нового диалога или продолжении прерванной разработки прочитайте `docs/DEV_STATUS.md`.
- Затем читайте только файлы, относящиеся к текущей задаче; полный обход репозитория не требуется.
- Проверяйте текущие branch/HEAD/status; не подменяйте актуальный локальный код старым GitHub-снимком.
- Исторические отчёты и тесты не являются автоматически текущими результатами.
- При продолжении перевода, оптимизации и сборке используйте [регламент](docs/TRANSLATION_WORKFLOW.md) и текущее состояние [DEV_STATUS](docs/DEV_STATUS.md); в каждом запуске проверяйте [BUGS](docs/BUGS.md), а проблемы со скриншотов обрабатывайте по регламенту.

## Назначение и платформа

- Клиентский русский перевод Hypixel SkyBlock, Minecraft **26.2 / Fabric / Java 25**.
- Сборка: Gradle Wrapper 9.5.1, Loom 1.17.21, Fabric Loader 0.19.5.
- Для ресурсов используется Resource Loader v1 из каталога Fabric API 0.161.0+26.2, не весь API.
- Minecraft использует необфусцированные имена; отдельный слой Yarn не добавлен.
- Во время игры перевод офлайн: готовые словари и ограниченные шаблоны, без LLM/сетевого переводчика.
- SkyblockRPG_RU — только офлайн-русификатор, mod ID `witherskyru`. Приватный Collector — независимый мод `skyblockrpgru_collector`: не добавлять его классы, API, согласия, сеть или зависимость от него в публичный JAR; [граница разделения](docs/PUBLIC_DISTRIBUTION.md). Старые checkpoints интеграции — история, не текущая инструкция.

## Фактическая архитектура

- `src/main/java/ru/wither/skyru/SkyRuClient.java` — инициализация, настройки, маршрутизация и ограничения.
- `OfflineDictionary.java` — точные записи, шаблоны, пользовательские overrides, ограниченные кэши.
- `NpcDialogueTranslator.java`, `NamedNpcTemplates.java`, `ChatNotificationTranslator.java` — диалоги/уведомления.
- `TooltipTranslation.java`, `ReviewedLoreStyles.java`, `EditorialContext.java` — перевод описаний и смысловых стилей.
- `src/main/java/ru/wither/skyru/mixin/` — подключения к GUI, tooltip, HUD, очереди чата и совместимым модам.
- `RenderContext.java` — контекст конкретного вызова рисования, а не сохранённый контекст кадра/мира.
- Чат переводится при добавлении в очередь отображения; GUI/HUD также используют display-time hooks.
- Нет универсальной системы «перевести весь текст один раз»; не приписывайте её существующему коду.
- Поставляемые таблицы: `src/main/resources/data/witherskyru/`; подготовка/источники: `translation-source/`.
- Внешние мосты активируются только для проверенных версий через `CompatibilityMixinPlugin.java`.
- SkyCubed NPC Dialogue Overlay: `SkyCubedDialogueBridge.java` и точечный Mixin после regex; проверены1.10.0/26.2 + SkyBlock API4.2.41 с хешами классов. Имя поиска/портрет, команды и Custom payload не переводить; границы — `docs/SKYCUBED_DIALOGUE_26_2.md`.

## Правила переводов и производительности

- По последнему указанию пользователя переводить партиями **по 1000 новых уникальных строк** с одним общим итогом; внутренние порции не являются отдельными целями, отчётами или поводом для JAR.

- Сохраняйте числа, уровни, значки, команды, ID, click/hover/insertion, текущие цвета и шрифты.
- Меняйте отображаемую копию, не исходный ItemStack, серверные данные, историю/подпись чата или ввод.
- Не переводите сообщения игроков/подписанный чат, технический F3 и защищённые имена/поля ввода.
- Неизвестные тексты и неподдержанные стили оставляйте исходными; не снимайте защиту ради покрытия.
- Учитывайте overrides: новые правила не должны обходить пользовательские замены.
- Для каждой партии сохраняйте авторский перевод, источник и проверки вариантов цвета/чисел/компонентов.
- Не выдавайте найденную строку, черновик или динамическую форму за отдельную готовую точную запись.
- Не обещайте 100% всех серверных фраз или нулевое влияние на FPS без соответствующих доказательств.
- Не добавляйте I/O/сеть/полные проходы словаря на кадр, неограниченные кэши или дорогой regex без границ.
- Кэшируйте неизменяемые планы, не текущие стили, компоненты, миры или результаты контекста рисования.
- Проверяйте восстановление scopes при исключениях; бенчмарки выполняйте последовательно, отдельно от тестов/игры.

## Безопасные изменения

- Сохраняйте чужие/незакоммиченные изменения; без запроса не сбрасывайте, не удаляйте и не переключайте ветки.
- Не отключайте функции/Mixin и не ослабляйте `require` ради зелёной сборки.
- Для новых версий сторонних модов сначала проверяйте байткод и реальные вызовы мостов.
- Исторические эталоны не переписывайте под результат; изменения ожиданий оформляйте явно в отдельных fixtures.
- Не устанавливайте JAR в рабочую сборку и не публикуйте изменения без соответствующего запроса.
- Не включайте в Git аккаунты, ключи, личные конфиги/журналы, игровые бинарники или кэши.
- Лицензии и атрибуцию сторонних данных/шрифтов сохраняйте; публичный NPC ID не равен API-ключу.

## Сборка и проверки (выбирать по риску задачи)

- Java 25; Windows: `./gradlew.bat build`, Linux/macOS: `./gradlew build`.
- Чистая сборка по необходимости: `./gradlew.bat clean build`.
- `./gradlew.bat test` запускает двадцать два main-based набора через `verifyTest*`, не JUnit discovery.
- Подготовка расширенных проверок: `./gradlew.bat writeVerificationClasspath`.
- Полный локальный прогон: `./tools/check_migration262.ps1 -HistoricalProject '<архив проекта 26.1.2>'`.
- Мосты: `./tools/check_vendors262.ps1 -Mods '<папка модов 26.2>'`.
- Python: `python -X utf8 -m unittest discover -s tests -p 'test_*.py' -v`.
- Игровой smoke требует `clientSmokeTestJar` и отдельного запуска; сама сборка не означает запуск игры.
- Подробности и ограничения тестовых данных — в `docs/MIGRATION_26_2_RU.md`, читать при необходимости.
- После существенных изменений актуализируйте `docs/DEV_STATUS.md`, разделяя факты, планы и предположения.
